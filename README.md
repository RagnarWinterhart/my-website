# Kintsugi Webpage

**By Rowan Lynn**

Kintsugi is a wiki and reference website for the **Pathfinder Society Kingmaker** campaign that I am a member of. The site serves as a centralized resource for players, providing quick access to campaign information, important NPCs, kingdom management details, and other useful references during gameplay.

In addition to serving as a campaign companion, this project was also an opportunity to practice modern front-end web development using HTML, CSS, and JavaScript.

## Features

* 📖 Organized wiki pages for campaign information
* 🎲 Interactive JavaScript dice roller
* 👥 Character and NPC reference pages
* 🏰 Kingdom management information and role descriptions
* 📱 Responsive layout for desktop and mobile devices
* 🎨 Custom styling built with CSS

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## Usage

The project is hosted using **GitHub Pages** and can be accessed directly through a web browser. No installation is required.

If you would like to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/RagnarWinterhart/my-website.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser or serve the project using a local web server.
